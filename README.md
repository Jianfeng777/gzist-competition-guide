# 广州软件学院计算机与人工智能竞赛导航

这是一个面向广州软件学院学生的简洁竞赛展示网站。学生端只有三个入口：

- 首页：快速了解本月适合做什么
- 年度赛事：按月份、等级和方向查找比赛
- 核心推荐：选择适合长期投入的赛事方向

## 信息原则

- 赛事官网只使用主办方或承办赛事平台的官方页面。
- 报名入口与赛事官网分开维护；没有核实到官方报名系统时，报名按钮保持不可点击。
- 不使用学校喜报、转载通知、搜索结果或聚合页面作为学生入口。
- 没有当届官方信息的赛事不在学生端展示。
- C 类赛事只在确认 2026 官方信息和计算机 / AI 参与价值后，作为“更多可选”加入。

## 每月维护

GitHub Actions 每月 1 日自动检查所有官网与已登记的报名入口，并创建一条月度复核 Issue。自动检查只负责发现链接异常，届次、报名状态和赛事内容仍需逐页人工确认。

学生网站位于 `site/`；核验脚本和 GitHub 工作流不会进入学生导航。合并到 `main` 分支后，Pages 工作流会自动发布 `site/`。
